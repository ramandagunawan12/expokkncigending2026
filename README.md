# KKN Cigending 2026 — Presentasi Web

Website presentasi interaktif untuk KKN Reguler Universitas Muhammadiyah Bandung di Kelurahan Cigending, Kecamatan Ujungberung, Kota Bandung.

## Cara pakai lokal
1. Ekstrak folder.
2. Buka `index.html` di Chrome/Edge.

## GitHub Pages
Upload seluruh isi folder ini ke root repository, pastikan `index.html` berada di root. Aktifkan **Settings → Pages → Deploy from a branch → main → /(root)**.

## Isi website
- Home + logo UMB dan KKN Cigending 1, 2, 3
- Profil Cigending
- Timeline 6 Agustus–5 September 2026
- Data ATS: 25 data (13 sudah sekolah, 2 tidak sekolah, 10 data tidak ditemukan)
- Program unggulan Ekonomi Sirkular
- Penerima manfaat RW 07, 09, 10
- Analisis impact lingkungan, ekonomi, kapasitas, keberlanjutan
- Dokumentasi survey, seminar, pembuatan pelet, pelatihan UMKM
- Penutup

Catatan: website tidak menampilkan nama, NIK, atau data identitas anak ATS; hanya agregat hasil verifikasi.
